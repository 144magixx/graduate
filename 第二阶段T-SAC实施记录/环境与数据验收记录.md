## 范围与事实冻结

`legacy_reference.replay_legacy` 仅导入旧环境，不导入旧训练，不反序列化历史模型，并恢复旧构造器改变的 NumPy 全局 RNG。冻结 `cover_output_0.csv` 上三步 `(0,1,5 W)、(10,2,10 W)、(20,3,15 W)`，两次回放一致。旧回报依次为 −4.525778073594062、−3.894080845910622、−3.558148814471596，终点旧束速率为 111721926.4059258、268412718.9851345、441307991.41201794 bps。该数值只作历史回归，不与新版 U 合并比较。

## 已实现的科学语义

- 显式旧坐标适配、Mbps 与 0.25 业务比例分离；标准 schema 不二次交换坐标。稳定 `beam_id` 与以 ID 表示的 `service_order`，不复制、不截断、不用处理序号替代身份。
- 实体、正需求、pending、allocated、skipped 分别保存；真实零需求可见而不进分母，模板 padding 不得增加满意度。原始需求排名冻结 group，再增强需求与重新排序；默认不增强宽度。
- 物理使用 float64、模型观察使用 float32。每束总功率均分槽，信号和两个方向的干扰共用同一份槽功率；同极化共享网格，异极化理想隔离，接收增益取受害端。
- 所有链路统一 `SINR = S/[10^(margin/10)·(N+I)]`，默认 margin 为 5 dB。不递推历史 dB SINR；纯函数从完整账本重算，环境仅缓存不随动作改变的几何。
- ALLOC 必须整体连续、在界内、同池全空闲、满足预算；非法动作在任何状态修改之前报错。候选字典默认 9551 个，SKIP 编号 0，无 ALLOC 时只保留 SKIP。末束也完整更新账本，预算用尽后继续记录 SKIP 至回合终点。
- 奖励仅为 `100 ΔU`，U 的正需求分母在回合内固定。受影响历史束全部重算、允许负奖励。空需求 reset 即终止，U/SINR 等无样本指标返回 null。
- 完整观察提供全部实体、历史动作、全局实际配置、当前槽干扰和剩余资源；兼容 205 维保留为近似观察。ActionSpec 数值签名进入观察，供回放和 SAC 拒绝不同动作语义。
- 前端快照隐藏 padding，稳定 ID 联动；轮廓按球面大圆角半径生成 GeoJSON，经纬度顺序显式转换。pending/SKIP 无 SINR 时使用 null。所有详情均来自当前完整账本。
- `state_dict/load_state_dict` 保存实际场景、完整分配前缀、cursor 和局部 RNG；恢复通过合法动作重放核验，不信任保存的累计指标。

## 验证

命令（工作目录 `D:\graduate\PPO4090`）：

```powershell
python -m unittest tests.horizon_tsac_20260920.test_data tests.horizon_tsac_20260920.test_environment -v
```

当前测试集合为 26 项。第一次补充空实体规模测试发现标准 loader 对空列表推断为 float 数组，已修正为显式 bool 并复测。验收覆盖：

1. 所有 100 份源文件的统计、坐标、比例、2.8° 原宽度保留；标准数据 roundtrip、非法字段与重复 ID 拒绝、增强确定性、group 不漂移。
2. 0/1/4/52/168/170/200/220 个正需求容量；真实 idle、空需求、padding 不加分；220 束完整 SKIP 终局。合成几何只标为接口 fixture，不计训练域覆盖。
3. 默认候选数量、条件前缀投影、槽 99 边界、中间占用洞、预算恰好 5 W 与 4.999 W、请求动作等于执行动作。
4. 单束两槽手算 Shannon oracle 与功率守恒；受害端异增益、极化隔离、干扰单调性、不重叠槽不变。
5. 同最终方案不同合法顺序得到完全相同速率；负奖励样例；随机合法轨迹的 `Σr=100U`、约束零违约与无缓存独立复算一致。
6. 非法动作拒绝后账本、cursor、RNG 均未改变；末步 ALLOC 可见；恢复后的快照与后续动作结果一致。
7. 两个相同局部 205 维观察、不同历史业务场景的明确混叠反例；完整观察能够区分。球面覆盖边界每点与中心大圆夹角均为正确半径。
8. 旧三步参考数值冻结与 NumPy RNG 恢复。
9. 独立评价默认拒绝非档位功率；第三阶段仅在显式 `power_mode="continuous"` 下接受连续每束功率。SKIP 也必须针对正需求实体，所有物理关键数组非有限时拒绝提交。
10. `load_scenario(..., rng=...)` 支持显式局部 RNG 的随机服务顺序；同 seed 顺序相同，完整正需求集合与固定 group 映射不变，未提供随机源时明确拒绝。

## 限制与未做

本验收证明当前工程/物理公式的一致性，不证明默认天线、频组、0.25 比例、宽度解释或 5 dB 语义是真实载荷事实。未完成正式长训练、五种子性能结论、第一阶段缺失原始业务/归属数据的生产域生成、真实 170/200/220 束泛化实验。独立评价器共享经手算验证的物理纯函数；没有把同一缓存的两个入口当独立真值。

环境对大场景采用完整线性重算，未加入近邻干扰裁剪；这保证参考语义但吞吐需由目标硬件实测。球面轮廓输出标准 GeoJSON，当前真实输入位于中国区域；跨日界线地图分片不属于本次真实数据验证范围。

数据/环境实现自审发现并修复：空实体数组 dtype、布尔 mask 值误接受、负 ID 与空槽哨兵歧义。模型代理交叉审查后另修正：非档位功率默认被接受、无业务 SKIP 被接受、极端增益非有限值缺少显式拒绝。跨模型审查发现的 ActionSpec 混池问题另见《算法代码审查.md》。
