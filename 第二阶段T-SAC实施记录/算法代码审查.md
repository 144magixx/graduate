## 结论

本次审查发现并修复一项 P1 回放动作语义隔离缺陷。当前已审范围内未留下已确认的 P1/P2 问题。结论限于数学与接口正确性，不代表正式性能提升、GPU 生产吞吐或完整项目安全审计。

## 已修问题

### P1：不同功率档表的经验可能被混入同一回放

原实现仅在 checkpoint 保存/恢复时检查 ActionSpec；`ReplayBuffer.add_episode` 未逐样本核验，`DiscreteSAC._batch` 只重建合法 mask。在预算充足且档位数量相同的条件下，`[5,10,…,50] W` 与 `[10,20,…,100] W` 可产生完全相同的 mask，却让同一 action ID 指向不同物理功率。如果版本字符串未改，旧经验会被当作新动作语义训练。

修复已闭环：`ActionSpec.signature()` 返回槽数、最大连续长度与完整功率档表；环境所有观察携带该签名。回放入池、回放恢复以及 SAC 更新前检查当前与下一观察，包括 terminal 观察；不允许终止状态绕过校验。SAC 检查点使用同一签名。候选排列由动作版本限定。

新增回归 `test_changed_power_grid_rejected_despite_identical_mask`，明确构造 mask 不变而功率表改变的反例。修复后的模型与环境组合测试已独立通过。

### 反向审查修复的环境问题

- P2：独立评价器原本接受任意正功率而不检查离散档位。现默认 `power_mode="discrete"` 并给出 `invalid_power_level` 违约；第三阶段连续功率仅在显式 `power_mode="continuous"` 下启用，仍检查每束上限及总预算。
- P2：SKIP 分支原先早于正需求检查，可能把真实 idle/padding 当作已跳过需求。现所有账本记录统一先检查正需求身份，指标分子也仅统计合法需求与实际分配。
- P2：极大但有限输入增益可能在指数运算后溢出。现几何耦合及槽功率、信号、干扰、噪声、SINR、速率逐项检查有限性；环境计算候选账本后再原子提交，因此失败不污染已有状态。

## 关键检查与证据

1. 条件 Actor 的起点、长度、功率 mask 从完整合法集合向前缀投影；联合概率为各条件概率乘积，非法候选概率严格为零。独立评分消融在整个合法 ALLOC 集合归一化，不对候选分块各自 softmax。
2. 确定性推理取完整联合分布全局 argmax；SKIP 独立处理，未通过 `-1` 索引读最后一个频槽。对应条件逐层贪心反例和强制 SKIP 测试通过。
3. 双 Q 在完整动作上分别形成标量后取最小；可加 Critic 也是先求和再取最小。目标计算全程 `no_grad`，terminated 直接得到 `y=r`，非终止的 truncated 保留 bootstrap。
4. Actor 的精确期望保留概率梯度，Q 与 α 均隔离梯度。三动作手算、有限差分、不同 Q 下策略向高价值动作移动的检查通过。
5. 温度损失使用正熵目标 `η log|A|`，梯度方向为低于目标提高 α、高于目标降低 α；强制单动作从温度均值中排除，整批单动作不调用 α optimizer。
6. 各状态只编码一次后分块计算无梯度候选 Q。critic 只对采样实际动作反传；微批按整个有效 batch 样本数累积损失，完成全部微批后各 optimizer 仅更新一次，最后 target 软更新一次。α 使用全部非强制样本总数归一化。分块/微批与不分块参考参数更新一致。
7. full_attention 实体分支没有任意 beam_id 位置嵌入；完整字段同时置换、current index 同步后分布保持一致。batch padding 不进入 attention/pooling。空实体 attention 使用显式安全占位，不会生成全 mask NaN。full_pool 表示波束集合池化，其频谱分支仍含位置注意力。
8. 回放采用不可变深拷贝，完整回合淘汰；显式标记截断片段；规模桶→回合→转移采样使用局部 RNG。checkpoint 保存 actor/两个 critic/两个 target、optimizer、α 和随机状态；确定性下一次采样和更新复现。
