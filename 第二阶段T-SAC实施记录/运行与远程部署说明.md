## 检查点与离线包

每个完整回合保存最新 `检查点.pt` / `检查点清单.json`，并在 `检查点存档/<checkpoint_id>/` 保留不可变副本和hash。恢复仅支持完整回合边界，生成新run_id，保留trial_id和父checkpoint。改变学习率、γ、回放/更新协议等不冒充精确续训。`--resume`指向可信的新实现检查点；旧full_model不可用于精确恢复。

通过 `telemetry.recorder.export_run(run_dir, destination)` 可生成SQLite一致性backup、已提交引用工件、CSV和本地静态页面。destination必须在源run之外。离线查看启动同一只读服务并指定 `--run-root <离线包路径> --static-root <离线包路径>/静态页面`；训练结束、无GPU、断外网时均可读取。模型重载仍需PyTorch，纯查看不加载模型。

第三阶段交接在各评估场景目录：`第二阶段分配结果.npz`、`第三阶段交接清单.json`、`导出复算验收.json`。NPZ加载使用allow_pickle=False，核查功率守恒、离散动作、频率网格、状态与mask、所有数组类型/维度/有限性，独立复算速率。第三阶段连续功率评价须显式选continuous模式，默认第二阶段仍严格检查离散档位。

## 远程准备

连接模板位于本目录 `远程连接配置模板.json`。填写本机私钥路径和远程绝对项目目录后通知Agent。只引用密钥文件路径，不在聊天或运行包中写入私钥内容。可见终端的密码登录不会自动授权另一执行会话；当前远程步骤等待用户补齐该配置。

构建独立包：

```powershell
python -m implementations.horizon_tsac_20260920.package
```

输出 `HorizonT-SAC-20260920远程运行包.tar.gz` 和中文SHA256清单。包不含私钥、虚拟环境、node_modules和历史模型；包含新代码、单测、前端构建、兼容旧源码及原始100份CSV。远程解包到新目录，避免覆盖已有项目；包内PPO4090是模块启动根目录。

远程使用Python3.10，先核对`torch.__version__`与`torch.cuda.is_available()`；已有匹配CUDA环境时复用其PyTorch，不盲目替换为CPU构建。依赖参考新包内 `运行依赖.txt` 和本地环境版本记录。最先运行pytest及一轮smoke，再安排正式长训练。新环境仅完成CPU验收，4090显存/有效batch256必须在远端另测。
