# 研究统计接口与消融配置说明

日期：2026-09-20。此交付实现多 seed 统计能力，没有执行正式多 seed 长训练。统计单元测试使用合成 fixture；真实接入验收仅为现有 2 个场景、1 个训练 seed 的短评估。

## 可运行接口

[research_stats.py](D:/graduate/PPO4090/implementations/horizon_tsac_20260920/research_stats.py) 提供两个无训练、无文件系统副作用的函数：

```python
summarize_runs(runs, metric="mean_satisfaction", phase="test",
               expected_seeds=None, resamples=2000, random_seed=0)

compare_runs(left_runs, right_runs, metric="mean_satisfaction", phase="test",
             expected_seeds=None, resamples=2000, random_seed=0)
```

每个 run 的输入结构为 `{"manifest": 完整运行清单, "episodes": 场景指标列表, "status": 权威运行状态}`。当前运行的权威状态来自 SQLite `runs.status`；不能把仍为 `created` 的初始 JSON 清单误当已完成。场景指标必须带真实 `phase`，或由评估清单声明该 phase。未声明来源阶段的摘要不会自动视为测试结果。

调用前按算法与模型配置分组。两个策略即便共享训练 `trial_id`，也应分别作为左右两组传入。数据未齐时返回缺失、排除原因与 `null`，不补零、不抛造区间。

## 估计与区间口径

- 首先在每个 run 内合并同一场景的重复评价；然后对共同场景等权、独立训练 seed 等权求均值。
- 同一 trial 的恢复分支仅保留最新完成后裔；失败分支单列。相同 seed 的额外 trial 不增加独立 seed 数。无法区分先后而指标不同的同谱系评估被排除，避免根据成绩挑 checkpoint。
- 配对差固定定义为 `right - left`，只使用左右共同训练 seed、共同场景；未匹配 seed 和场景显式列出。
- 95% bootstrap 同时对训练 seed 与场景抽样。一次重采样内，各 seed 共享场景索引；左右算法共享配对索引，保留共同测试场景的相关性。
- `scenario_ci95` 是场景诊断区间；`seed_ci95` 是包含训练 seed 变化的两层区间。只有 1 个训练 seed 时，后者必须为 `null`，不能把场景波动冒充训练 seed 不确定性。
- 未知 root/归属仅保留候选场景层结论；若多个被评价候选共享同一 root，当前不提供 root 聚类区间，禁止正式排名。不能只凭清单一个布尔声明推导 root 独立。

`ranking_available` 比数值差可用更严格：必须为测试阶段、至少 5 个独立 seed、有预登记 `expected_seeds` 清单、无缺 seed/场景、无失败/身份歧义、相同可比条件、可追溯独立 root。验证阶段与短跑仍可给配对诊断，不产生正式排名。

## 兼容性

物理完整数值配置、物理/动作/指标/schema 版本、预算、完整功率档与槽定义、数据单位/缩放/坐标/group/顺序、冻结划分 hash 均参与校验。版本号相同但物理数值不同，仍拒绝比较。

模型结构及观察消融允许不同。不同 reward 版本或 scale 禁止 return 对比，但在物理与业务指标口径一致时允许比较满足度等业务结果。没有有效 root/assignment 标记时不提供 `J_root` 对比。
