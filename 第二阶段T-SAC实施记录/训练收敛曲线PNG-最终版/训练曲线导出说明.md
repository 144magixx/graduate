# 训练收敛曲线PNG最终版

已保存12张单运行曲线与3张分组对比，共15张PNG，240 dpi，共1971个真实逐回合训练点。Spectrum seed43已完成300回合，累计42632环境步、41633次更新。

seed43严格拼接gpu4持久恢复前1–150回合与gpu2最终结果中的150条新增记录（151–300回合）。原gpu4旧尝试151–160单列排除。图中保留150回合恢复点，平滑在该处重新开始。共同CNN父模型训练100回合单列，不计入新增训练横轴；两续训seed不冒充从零独立多seed。seed42残差模型实际在墙钟预算下止于271回合。

其余11条训练流及13张固定图保持已验收版内容和PNG字节一致，仅重绘12号seed43单图与15号配对图。此前244回合版本的目录和ZIP均保留。本包较此前多56个真实训练点，1915增至1971；旧版仅作为来源证据，不再作为本版完成状态。

浅线为逐回合原值，粗线为后向10回合移动均值，不足10回合用已有样本。平滑为因果统计，不是置信区间。累计回报R=100×U，两纵轴是同一奖励口径；未将终局validation分数或test分数混入训练曲线。图中列出算法、seed、网络、实际生效学习率及SAC/PPO/DQN专属参数。静态Fixed、Greedy、Random无训练曲线。

## 数据与复现

`训练曲线数据与配置.json`保存12条流的全部点、配置、run_id及来源SHA。`绘图数据原件/gpu2完成状态初查原件.json`为最终结果获取原件，使用其中`run_files.训练结果.json`和`run_files.运行清单.json`；其SHA与原始`gpu2完成状态初查.json`相同。旧日志原件及冻结11流记录同包保存。

在本目录执行：

```powershell
D:/graduate/PPO4090/.venv-horizon/Scripts/python.exe -X utf8 绘制训练收敛曲线.py --all
```

可离线复现全部15张；不加`--all`只重绘12/15并核验其余13张哈希。脚本不联网、不导入训练入口、不读取评价分数，也不修改原版文件。`PNG导出与核验清单.json`记录图片哈希、尺寸、1971点核验及恢复拼接证据。
