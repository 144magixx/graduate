# Horizon 学习链路独立审查与动作价值诊断

2026-09-21。本次只读审查旧训练链，探测仅使用冻结训练集 `cover_output_52`，未访问 test、改旧参数、训练或远端产物。原始数值、模型 SHA、来源检查点、配置和四个可重放状态的账本保存在[诊断数值](Horizon与CNN动作价值独立诊断数值.json)。

**结论：未发现能解释此次差距的 SAC 更新公式工程错误；有表示与优化方面的设计风险，但不能据此宣称完整因果已经证明。** 既有 SAC 与更新调度回归共 23 项通过（10.34 秒）。

- `rl/sac.py` 的双 Q 在完整动作上先取最小再求期望；仅 terminated 关闭 bootstrap；目标无梯度、actor 更新隔离 Q 与 alpha 梯度；微批按完整 batch 归一化、每次只更新一次；alpha 符号和 tau 软同步正确。
- 实际 H 与 MLP/CNN-SAC 的学习率、批量和训练预算相同：actor `1e-5`、critic/alpha `1e-4`、初始 alpha `0.01`、gamma `1`、tau `0.005`、batch/microbatch `64`、replay `4000`、warmup `1000`。H 同时改变了观察、编码器、actor 和 critic，不能把差异归结为 Transformer 单项。
- 回放按已完成回合入池，当前回合在终止前不可采样。这是已冻结、各 SAC 共同遵守的协议；带来最多一回合的数据延迟，并非丢失经验或更新次数错误。后续可增加经验年龄诊断，第一轮架构对照宜保持不变。

实际最终权重在同一合法随机 ALLOC 轨迹的 cursor `0/25/60/100` 上，H 的 alpha 为 `0.0082013`，CNN 为 `0.0299322`。H 的 SKIP 概率为 `0.0001093/0.0000291/0.00000459/0.0000559`，各状态联合 MAP 均为 ALLOC。因此，不能把此前 PPO 的 SKIP 解码机制直接当作 Horizon 本次低分的原因。

每状态抽取相同的 32 个合法 ALLOC，另纳入两个 actor MAP 与 critic 最大 Q 候选。去除 SKIP 后，H 候选 Q 的标准差为 `0.666/0.678/0.720/0.382`，CNN 为 `5.495/6.352/6.069/6.550`。H 的分配动作区分更弱，但不恒定；H 的 Q 与候选即时奖励相关系数为 `0.643/0.369/0.640/0.270`。四状态 H actor 的即时奖励为 `0.263/0.361/0.529/0.719`，CNN 为 `0.220/0.666/0.719/0.719`。**即时奖励不是长期 Q 真值，Q 跨度更大也不等于更准确；这里只支持进一步检查表示与候选区分，不能称 Q 完全塌缩。**

两个数学反例说明独立风险，均不是实际运行的因果证明：

1. 9550 个 ALLOC 加一个 SKIP，令 SKIP 概率为 `0.001`、其余总概率 `0.999` 均分，则每个 ALLOC 只有 `0.0001046`，联合 MAP 仍是 SKIP。`H_target=η log(9551)` 也不约束 gate：η=`0.2/0.5/0.8` 时，SKIP 分别约为 `0.8467/0.5744/0.2628` 的均匀分配混合仍可恰好满足目标熵。初始 gate 约半数 SKIP，而 uniform-ID warmup 的 SKIP 仅 `1/9551`，也存在共同的分布切换风险。
2. 两步玩具问题中，立即分配得训练奖励 `0.05` 后只剩 SKIP；先 SKIP 得零、下一步保留 9551 个零奖励动作。alpha=`0.01` 时后者的熵收益 `alpha log(9551)=0.09164` 大于前者。预算相关 mask 会让标准最大熵目标偏好保留动作空间；这符合 SAC 定义，不是实现符号错。相对均匀策略的熵正则或分层熵只能作为具名新目标实验，不能悄悄替换旧目标。

建议首轮新实验保留已经较强的 CNN 频谱路径，用零输出投影的全局 Transformer 残差、独立 actor 和 additive critic。从同一 CNN 权重初始化新模型与 CNN 配对控制，验证初始 actor/Q/targetQ 完全一致；不得在残差后额外归一化破坏恒等关系。双方一致重置或继承 alpha、优化器和回放，并记录追加交互预算及独立新 trial。首步全局分支深层梯度为零是零投影的正常现象，后续应验证它获得梯度。第一轮不同时修改奖励、η、解码及回放协议，以免继续混杂归因。

API 边界补充：旧 SAC 类直接 `load_state_dict` 没有独立检查全部物理/数据配置，正式入口的 `artifacts.load_checkpoint` 已执行该检查；未发现本次运行绕过外层加载的证据，故不把它列为性能原因。新 weights-only 初始化应自行严格校验来源、语义和全部张量，并清楚标为新实验而非精确续训。
