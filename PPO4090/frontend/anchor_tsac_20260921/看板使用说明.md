# Anchor T-SAC 只读研究看板

从 `PPO4090` 根目录启动：

```powershell
python -m implementations.anchor_tsac_20260921.dashboard --host 127.0.0.1 --port 8765
```

打开 `http://127.0.0.1:8765/`。服务默认只读 `ANCHOR_OUTPUT_DIR`，不导入训练入口、模型权重或 CSV。页面只提供波束分布、训练曲线、频谱分配、单步回放和实验对比；不包含启动、暂停或修改训练的控件。

`实现说明` 来自 `GET /api/v1/implementation`：Anchor 使用 14 token 纯 Transformer（d128 / 8 头 / 2 层）、独立 Actor 和可加 Critic。`legacy_scaled205` 仅恢复旧输入数值尺度，底层仍为新物理账本，不可解释为旧环境回滚。
没有运行时，列表、回放、曲线和对比保持空态；看板不导入 Horizon/Spectrum 历史结果来代替 Anchor 证据。实际运行的观察适配器、`from_scratch` / `weights_only_not_exact_resume` / 精确 resume 谱系、源 hash 与 new trial 只能从运行清单读取；权重迁移不可标示为精确续训。
前端源码改变后，在此目录构建：

```powershell
npm run build
```

生产静态文件位于 `dist/`。可以使用现有的前端依赖目录进行离线构建；`node_modules` 不作交付包内容。
