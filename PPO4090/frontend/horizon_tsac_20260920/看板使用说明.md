在 `D:\graduate\PPO4090` 运行：

```powershell

```

打开 `http://127.0.0.1:8765/`。默认扫描 `project_paths.HORIZON_OUTPUT_DIR`，查看历史不导入 Actor、训练入口或 Torch，不要求 GPU。

首次构建或源码改变后，在当前前端目录执行 `npm ci`、`npm run build`。依赖版本已锁定到 `package-lock.json`；生产包位于 `dist/`，包含本地 React、CSS 和脚本。地图使用经纬度网格与环境生成的球面模型覆盖多边形，不请求网络瓦片、在线字体或 CDN。


## 五个视图

- 波束分布：隐藏 padding，点击稳定 beam_id 查看真实需求、速率、功率及已记录的逐槽 SINR；逻辑池、状态和着色可筛选。覆盖多边形来自模型，不代表用户归属或真实覆盖率。
- 训练曲线：横轴使用 env_step、update_step、episode 或 elapsed_seconds；按 train/validation/test 分系列。原值与优化窗口统计分别标识；窗口 min/max/count 保留，无法恢复的逐 update 值不伪造。
- 频谱分配：逻辑池与物理频率使用同一共享状态；点击波束保留跨模块选择。池占用率与物理频率覆盖率分别显示，SKIP 没有资源块。
- 单步回放：reset/恢复锚点、前后一步、播放倍速、终局和任意 step；从已存关键帧及 delta 重建，不重新采样策略。动作前后与受影响历史束均可查。
- 实验对比：仅使用独立 validation/test 回合；按算法和模型配置分组，保留 seed、恢复谱系、失败和缺失信息。物理、预算、数据语义或 ActionSpec 不兼容会标记；单 seed 不生成训练 seed 区间。训练域覆盖直接读取同一份覆盖审计。

日志侧栏可按级别、正文和选中波束筛选、分页并跳转已记录步骤。更细的 component/event_type/phase/scenario/episode 筛选由 REST API 提供，当前界面尚未为每个筛选参数提供独立控件。

历史模式不会被后台的新记录抢占；点击“实时跟随”才切换到最新回合末步。SSE 仅通知已提交事件，最多每秒两次合并页面刷新。页面区分查询连接状态、最后提交时间、训练心跳和运行终态。

## 记录与完整性

运行目录包含中文 `运行记录.sqlite`、`运行清单.json`；SQLite WAL/FULL 是查询事实源。`诊断日志.jsonl` 是按 10 MiB 轮转的诊断镜像，镜像损坏或缺少末尾不替代 SQLite。异常会尽力记录前 20 个 CPU 动作上下文；writer 死亡或核心队列超时会抛出 RecorderError，训练控制器必须停止。

全部回合保留基本轨迹；第 0 帧、每 20 步和终局/截断写完整关键帧，其余保存资源变化与波束动态字段。新记录逐步保存完整状态 hash，校验动作前缀与请求回放状态。旧实现阶段生成但没有状态 hash 的新包历史记录返回 `state_hash_verified=false`，不能称为通过此项校验。

`GET /api/v1/runs/{id}/integrity` 和运行列表提供同源完整性状态：已引用文件丢失、SHA-256 不匹配、场景快照未引用都会如实报告，查看操作不删除或修复原文件。hash 采用分块读取、逐文件缓存，不在 SQLite 读事务中遍历大文件。

导出使用 SQLite 在线 backup 固定一个已提交水位，按该数据库的 artifact 引用复制并校验文件。中文 CSV 是派生导出，不是另一份可写真值；`数据哈希.json` 保存离线包的文件摘要。

## 已知边界

- 当前轮廓和网格可离线查看；尚未打包行政区底图。未知波束宽度语义的输入应只显示中心与原值。
- 查询、可靠性和真实浏览器交互已验证；千万步运行的磁盘容量、每百万步存储成本、长时间 WAL 和可选 detail 归档策略仍需实际运行验收。
- writer 当前一条核心消息一个 FULL 事务；吞吐开销尚未达到方案中的 5% 目标，不以减少必要轨迹宣称通过。具体测量在项目实施记录中另列。
- 首版没有训练中途精确续训 CLI；Recorder 支持中途 resume anchor 的独立基本回放，训练控制器的精确恢复边界以其自身文档为准。
- 正式多 seed 统计代码可用，不等于已经完成多 seed 科学实验；来源不明和域覆盖缺口不会被候选文件数量掩盖。
